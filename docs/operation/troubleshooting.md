# Troubleshooting

## 1. 目的

複数アプリ連携で発生する障害の切り分け方法を記録する。

## 2. 切り分けの基本順序

1. 対象アプリと発生環境を特定する。
2. 認証サーバーが稼働しているか確認する。
3. 参加アプリから認証サーバーへの通信を確認する。
4. アプリ登録、URL、環境変数を確認する。
5. コールバック・認証結果検証のログを確認する。
6. セッション・Cookie・Redis等の状態を確認する。
7. ロール・利用許可による拒否かを確認する。
