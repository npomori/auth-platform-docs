# Security

## 1. 基本方針

認証基盤は複数アプリの信頼境界となるため、認証・認可・セッション・秘密情報・監査の各領域を分けて管理する。

## 2. 確認項目

- TLSによる通信保護
- Cookie属性とCSRF対策
- OAuth等の連携パラメーター検証（採用方式に応じる）
- コールバックURLの許可リスト
- 秘密情報の保管・ローテーション
- 最小権限の原則
- サーバー側での認可判定
- ログへの個人情報・秘密情報の過剰出力防止
- 監査ログの保護と保持
- 依存パッケージ・脆弱性管理
- バックアップと復旧テスト

## 3. インシデント対応

秘密情報漏えい、アカウント侵害、セッション悪用、認証サーバー停止時の連絡・封じ込め・失効・復旧手順を定義する。
