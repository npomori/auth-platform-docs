# Deployment

## 1. 目的

認証サーバーと参加アプリのデプロイ構成・手順を管理する。

## 2. 環境区分

開発、検証、本番の環境を区別し、URL、接続先、秘密情報、データを混在させない。

## 3. デプロイ記録

各コンポーネントについて、デプロイ先、実行方式、公開ポート、リバースプロキシ、TLS、永続化領域、ヘルスチェックを記載する。

## 4. リリース手順

1. 変更内容と影響範囲を確認する。
2. DB変更・設定変更の有無を確認する。
3. バックアップとロールバック手順を確認する。
4. 検証環境で動作確認する。
5. 本番へ反映し、認証・連携・ログを確認する。
