# App Integration Specification

## 1. 目的

参加アプリが認証サーバーと連携する際に満たすべき共通インターフェースとルールを定義する。

## 2. 参加アプリの要件

- 認証サーバーに登録されていること
- 登録済みの識別情報・接続設定を使用すること
- 許可されたコールバックURL等を使用すること
- 認証結果を規定の方法で検証すること
- アプリ側のセッションと権限を適切に管理すること

## 3. インターフェース

APIのパス、HTTPメソッド、認証方式、要求・応答スキーマ、エラーコードを一覧化する。詳細は実装確認後に確定する。

## 4. バージョニング・互換性

共通インターフェースのバージョン、後方互換性、廃止予定、移行期間を定義する。
