# Session Management Specification

## 1. 目的

認証サーバーと参加アプリそれぞれのセッション管理責任、およびログイン・ログアウト時の挙動を定義する。

## 2. セッションの責任分界

- 認証サーバー: 共通認証状態・認証サーバー側セッションを管理する。
- 参加アプリ: 自アプリへのログイン状態とアプリ側セッションを管理する。
- セッション間の同期・失効方法は実装仕様に基づいて明記する。

## 3. Cookie・有効期限

Cookie属性（Secure、HttpOnly、SameSite、Path、Domain）、有効期限、更新条件、アイドルタイムアウト、絶対有効期限を記載する。

## 4. ログアウト

- 参加アプリ単体のログアウト
- 認証サーバーのログアウト
- 他の参加アプリのセッションへの影響
- セッション失効通知・再検証方式

## 5. セキュリティ要件

セッションIDの再生成、CSRF対策、セッション固定攻撃対策、失効済みセッションの拒否を定義する。

## 6. 実装との照合事項

実際のCookie名、保存先、TTL、更新・削除処理、Redis等の利用有無を確認して記載する。
