# User Management Specification

## 1. 目的

認証サーバーが管理する共通ユーザー情報と、参加アプリが利用できるユーザー情報の範囲を定義する。

## 2. ユーザー管理の責任

- 共通ユーザーの作成・招待・停止・削除等は認証サーバー側の仕様に従う。
- 参加アプリは、必要な範囲でユーザー情報を利用する。
- アプリ固有プロフィールを持つ場合は、共通ユーザー情報と分離する。

## 3. ユーザー識別

参加アプリ間で同一ユーザーを識別するための不変IDを定義する。メールアドレス等、変更され得る属性を主キーとして扱わない。

## 4. 状態・ライフサイクル

招待、登録、利用中、停止、削除などの状態と、参加アプリへの反映方法を記載する。

## 5. プライバシー

参加アプリに提供する属性を必要最小限にし、目的外利用を避ける。
