# Data Sharing Specification

## 1. 目的

認証サーバーと参加アプリ間で共有するデータ、共有方法、データ管理責任を定義する。

## 2. データ分類

| データ | 管理主体 | 参加アプリへの提供 |
|---|---|---|
| 共通ユーザー識別子 | auth-server | 連携に必要 |
| 共通ユーザー属性 | auth-server | 必要最小限 |
| 共通ロール・利用許可 | auth-server | 認可に必要な範囲 |
| アプリ固有プロフィール | 各参加アプリ | 原則アプリ内 |
| アプリ固有業務データ | 各参加アプリ | 原則アプリ内 |

## 3. 共有方式

API、署名付き情報、トークン等の具体的方式は実装に基づき記載する。DBを直接共有する場合は、接続権限・テーブル所有者・スキーマ変更責任を明確にする。

## 4. データ最小化・保持

提供属性、保持期間、削除・訂正要求への対応、監査ログの扱いを定義する。
