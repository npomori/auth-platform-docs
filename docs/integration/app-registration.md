# App Registration

## 1. 目的

新しい参加アプリを認証サーバーに登録する際の手順と確認項目を定義する。

## 2. 登録情報

実装に合わせて、アプリ識別子、表示名、環境、許可コールバックURL、必要な権限、連絡先等を記録する。

## 3. 登録手順

1. アプリの用途・管理者・公開URLを決定する。
2. 開発・検証・本番の環境を区別する。
3. 認証サーバーにアプリを登録する。
4. 発行された識別情報・秘密情報を安全に設定する。
5. コールバックURLと許可範囲を検証する。
6. 認証・ログアウト・権限確認をテストする。

## 4. 秘密情報の管理

秘密情報をGitにコミットしない。環境ごとに分離し、漏えい時のローテーション手順を用意する。
