# Participant App Development Guide

## 1. 目的

認証プラットフォームに新しい参加アプリを追加するための開発ガイド。

## 2. 開発の基本方針

参加アプリは [participant-app-base](https://github.com/npomori/participant-app-base) を共通基盤として利用する。具体的な導入方法・APIは同リポジトリの最新ドキュメントを参照する。

## 3. 開発手順

1. アプリの目的・利用者・必要な権限を整理する。
2. `participant-app-base` の導入条件と対応バージョンを確認する。
3. 認証サーバーに参加アプリを登録する。
4. 環境変数・接続先・秘密情報を設定する。
5. 認証開始、コールバック、ログイン状態の確立を実装する。
6. 共通ロールとアプリ固有ロールを使った認可を実装する。
7. ログアウト・セッション失効・エラー処理を確認する。
8. テストとセキュリティ確認を行う。

## 4. 参照実装

[sample-app](https://github.com/npomori/sample-app) を参照実装として利用する。ただし、サンプルの設定値や簡略化された実装を本番環境へそのまま適用しない。

## 5. リリース前チェックリスト

- [ ] アプリ登録とコールバックURLが正しい
- [ ] 秘密情報が安全に管理されている
- [ ] 認証結果の検証をサーバー側で実施している
- [ ] 権限判定をサーバー側で実施している
- [ ] ログアウトとセッション失効を確認した
- [ ] エラー・監査ログに秘密情報を出力していない
- [ ] 既存アプリや共通基盤との互換性を確認した
